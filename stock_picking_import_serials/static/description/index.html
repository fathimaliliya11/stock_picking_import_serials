Stock Picking Import Serials

Import Serial/Lot Numbers Easily from Excel

This module allows users to import serial or lot numbers into stock pickings directly from an Excel file. It simplifies data entry for serialized inventory operations such as receipts, internal transfers, and deliveries.

Features

  • Import serial/lot numbers from Excel
  • Attach imported serials to picking lines automatically
  • Supports Excel (.xlsx) format
  • Validation for missing or duplicate serials

How It Works

  1. Open any stock picking (Receipt, Delivery, or Internal Transfer).
  2. Click the “Import Serials” button.
  3. Upload your Excel file and confirm.

Example Excel Format

ProductLot / Serial Number(s)Quantity
Product ASN0011
Product BSN0021
